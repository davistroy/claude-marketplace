# xquik-x-data

Xquik REST API and remote MCP workflows for X data, exports, monitoring, and webhooks.

## Installation

```text
/plugin install xquik-x-data@troys-plugins
```

See [root README](../../README.md) for marketplace setup instructions.

## What's Included

- **1 Skill** - `/xquik-x-data` for REST API, OpenAPI, remote MCP, export, monitor, and webhook planning.
- **Optional MCP Config** - Connects Claude Code to `https://xquik.com/mcp` with `XQUIK_API_KEY`.
- **Source Links** - Routes users to current docs, OpenAPI, MCP manifest, and source repository.

## Setup

Set an API key before using REST or MCP examples:

```bash
export XQUIK_API_KEY="your-api-key"
```
