# bpmn-plugin

BPMN 2.0 workflow tools: XML generation from natural language/markdown, and conversion to Draw.io format. Includes bundled bpmn2drawio Python tool.

## Installation

```text
/plugin install bpmn-plugin@troys-plugins
```

See [root README](../../README.md) for marketplace setup instructions.

## What's Included

- **2 Skills** — `/bpmn-generator` (NL/markdown to BPMN 2.0 XML) and `/bpmn-to-drawio` (convert BPMN XML to Draw.io format)
- **Bundled Python Tool** — bpmn2drawio converter for programmatic BPMN to Draw.io transformation
- **References** — BPMN element documentation and best practices
- **Templates** — XML templates and swim lane configuration examples

Full documentation available in [root README](../../README.md#bpmn-plugin).
