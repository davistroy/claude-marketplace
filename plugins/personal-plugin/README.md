# personal-plugin

Personal Claude Code commands and skills for documentation review, architecture analysis, git workflows, document processing, and multi-source research.

## Installation

```text
/plugin install personal-plugin@troys-plugins
```

See [root README](../../README.md) for marketplace setup instructions.

## What's Included

- **23 Commands** — documentation analysis, architecture review, git workflows, document processing, security scanning
- **24 Skills** — architecture review orchestration (9-agent parallel domain specialists), wiki management, research automation, device auditing, and more
- **9 Specialized Agents** — domain experts for architecture review (security, platform, data, performance, integration, QA, software, risk/compliance, solutions)
- **Workflow Hooks** — git integration, CLAUDE.md rules for automatic behavior

Full capability list available in [root README](../../README.md#personal-plugin).

## Python Tools

Bundled tools include:
- Feedback document generator (feedback-docx-generator)
- Visual explanation generator (visual-explainer)
